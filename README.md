# loon-rules

给 Loon 用的远程规则。目前有 **AI**、**Notebook**、**OKX**。

Gemini Notebook / NotebookLM 用 [Loon/Notebook.list](Loon/Notebook.list)，要放在 AI 规则前面。

Muse 已并入 [Loon/AI.list](Loon/AI.list)。不要再单独订阅 `Muse.list`。
## KISS Translator（Scripting 兼容版）

适用于 iOS Safari 的 Scripting Safari 浏览器脚本。

**一键导入：** [点击安装 KISS Translator](https://raw.githubusercontent.com/yiyu12138/loon-rules/main/Loon/KISS-Translator/KISS-Translator-Scripting-v2.1.0.user.js)

> 如果点击后没有自动进入 Scripting，请在 Scripting → Safari 浏览器脚本 → 从 URL 安装中粘贴上面的地址。

脚本文件：https://raw.githubusercontent.com/yiyu12138/loon-rules/main/Loon/KISS-Translator/KISS-Translator-Scripting-v2.1.0.user.js
